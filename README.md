# video-course-teacher.skill

"让课程真的把你教会。"

License: MIT Python 3.9+ Codex AgentSkills

你买了课，收藏了课，打开了课。  
然后呢？  
看完一节，感觉懂了；关掉视频，又不会写了。

`video-course-teacher.skill` 要解决的就是这个问题：  
把视频课变成一套真正能推进的学习系统。

你给我一个视频课链接，我不会只帮你“总结一下”。  
我会先读课程大纲，整理学习路线，写进 Obsidian；  
再学习课程的讲课顺序、例子风格和难度；  
然后像老师一样，用文字版给你上课；  
上完课，再布置和课程相似的作业；  
你做完，我批改、总结、记录错题，并更新学习进度。

不是“看过了”。  
是“讲过了、写过了、错过了、改过了、记住了”。

## 它能做什么

提供视频课链接、课程目录、截图、字幕、代码或讲义后，Skill 会把课程拆成一套学习流程：

```text
课程大纲归纳
-> Obsidian 学习进度
-> 文字版讲课
-> 跟课代码
-> 课程相似作业
-> 作业批改
-> 错题与报错本
-> 阶段总结
-> 更新进度
```

## 核心特性

| 能力 | 说明 |
| --- | --- |
| 课程大纲归纳 | 读取课程标题、分集目录、公开资料，整理学习路线 |
| Obsidian 进度管理 | 自动维护课程计划、每日学习、代码练习、作业状态 |
| 文字版讲课 | 先上课，再布置作业，按初学者能懂的方式讲 |
| 课程风格对齐 | 模仿课程的讲解顺序、例子类型和难度 |
| 跟课代码 | 必要时写入 `.py` 文件，方便你直接运行 |
| 作业系统 | 作业和课程内容挂钩，难度相近，不乱出题 |
| 作业批改 | 批改代码、报错、运行结果，给出掌握等级 |
| 错题与报错本 | 记录错误现象、原因、正确写法和判断方法 |
| 复习机制 | 记录下次复习日期，支持当天、3 天后、7 天后复习 |
| 资料可信度分级 | 区分官方资料、公开目录和推断内容 |

## 课堂状态机

这个 Skill 不会一上来就甩作业。

它有固定课堂状态：

| 状态 | 说明 |
| --- | --- |
| `syllabus` | 整理课程大纲 |
| `teaching` | 正在上课 |
| `homework` | 布置或等待作业 |
| `review` | 批改作业 |
| `summary` | 总结并更新进度 |

硬规则：

```text
没有上课，不布置作业。
```

## 资料可信度

视频课不一定能直接读取完整内容，所以 Skill 会标记资料来源：

| 等级 | 来源 |
| --- | --- |
| A | 官方讲义、源码、字幕、用户截图/材料 |
| B | 公开视频标题、分集目录、课程页摘要 |
| C | 根据同类课程和公开信息推断 |

如果不是 A 级资料，它会明确说是：

```text
课程对齐版
```

不会假装自己看到了视频原文。

## Obsidian 结构

默认写入：

```text
C:\Users\Administrator\Documents\Obsidian Vault
```

推荐结构：

```text
Python学习/
├── 课程计划/
│   ├── <课程名>学习计划.md
│   ├── <课程名>学习进度.md
│   └── <课程名>错题与报错本.md
├── 每日学习/
│   └── DayXX-<主题>.md
└── 代码练习/
    └── DayXX_<主题>/
        ├── 01_lesson.py
        ├── 02_tasks.py
        ├── 03_reference_answer.py
        └── 04_review.md
```

## 使用方式

对 Codex 说：

```text
使用 $video-course-teacher 学这个视频课：<视频链接>
```

或者：

```text
用 $video-course-teacher 继续上次的 Python 课
```

也可以提交作业：

```text
我完成了 Day01 作业，帮我批改并更新进度
```

## 效果示例

用户：

```text
使用 $video-course-teacher 学这个黑马 Python 进阶视频课
```

Skill：

```text
当前状态：syllabus

我会先读取课程公开信息，归纳课程大纲，并在 Obsidian 中创建学习进度文件。
这门课主线包括：面向对象、装饰器、网络编程、多任务、正则、数据结构和算法。

下一步进入 Day01：面向对象入门。
```

上课时：

```text
当前状态：teaching

本节目标：
1. 理解类和对象
2. 理解 self
3. 理解 __init__

类可以理解为图纸，对象是根据图纸造出来的具体东西。
比如 Washer 是洗衣机类，haier 是一个具体洗衣机对象。
```

作业时：

```text
当前状态：homework

现在布置作业：写一个 Student 类。
要求：
1. 有 name、age、score 三个属性
2. 有 introduce 方法
3. 有 is_passed 方法
```

批改时：

```text
当前状态：review

掌握度：B

你已经理解了 __init__ 的作用，但 self.score 和 score 的区别还不够稳。
我已把这次问题记录到错题与报错本，并安排 3 天后复习。
```

## 适合谁

- 买了很多课但学不完的人
- 看视频能懂，自己写代码不会的人
- 想把 B 站课程变成系统学习计划的人
- 需要 Obsidian 持续记录学习进度的人
- 编程初学者
- 想让 AI 像老师一样长期带学的人

## 不适合谁

- 只想要视频逐字稿的人
- 不愿意写作业的人
- 只想收藏路线但不执行的人
- 要求 AI 假装看过无法访问的视频内容的人

## 写在最后

课程不会因为你收藏了它而进入你的大脑。  
知识也不会因为你听懂了一遍就变成能力。

真正的学习，是你亲手写过，亲自错过，被指出来，再改对。  
然后下次遇到类似问题，你能自己认出来。

`video-course-teacher.skill` 不是帮你“总结课程”的。  
它是把一门课拆成每天能走的一小步，陪你真的走完。

别只收藏课程。  
让课程把你教会。
