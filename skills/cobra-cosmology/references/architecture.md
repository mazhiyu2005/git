# Cobra/C资料宇宙论档案架构

## 总体结构

这批资料形成一个从宇宙起源到地球解放叙事的层级体系：

1. 本源宇宙论：神圣本源/绝对、偶然/主要异常、十二道光、自由意志。
2. 宇宙能量结构：量子尺度、11维时空、七层面、多维身体、光体、高我。
3. 黑暗与冲突史：主要异常被直接体验后产生负面选择，黑暗势力、执政官、奇美拉、银河战争、地球隔离、植入物与帷幕。
4. 地球局势与事件：抵抗运动、光明势力、金融/社会转变、事件、揭露、扬升窗口、集体冥想。
5. 灵魂与关系结构：星际种子、灵魂家族、灵魂伴侣、双生灵魂、神圣结合。
6. 女神/蔷薇线：女神能量、蔷薇圣女团、极性能量疗愈、女神漩涡点、神圣女性回归。
7. 实践与象征系统：冥想、连接高我、五大维身体清理、三角合一、安塔瑞昂转换、圣杯/卡巴拉/生命树、圣哲曼与飞升叙事。

## 核心概念链

### 起源链

神圣本源/绝对 与 偶然/主要异常 形成张力，资料体系认为宇宙由此显现。主要异常本身被描述为随机性、量子偶然、反生命半意识场或未整合的异常；当自由意志选择直接体验并技术性放大它时，产生黑暗势力与痛苦结构。

### 维度链

宇宙不是单一物质层，而是由多个层面构成。常见对应为：

- 物质层/肉体：日常可见现实。
- 电浆体、以太体：与植入物、异常电浆、能量网格、帷幕相关。
- 星光层/情绪体：欲望、情绪、死后中间状态、非物质实体活动。
- 心智层/心智体：思想、理解、编程、较高心智体的合一意识。
- 因果体/灵魂层、高我、真我/菩提等更高层：目的、洞见、光体、灵魂连接。

### 冲突链

主要异常 -> 负面自由意志选择 -> 黑暗势力/执政官/奇美拉 -> 地球隔离 -> 植入物/帷幕/矩阵 -> 人类遗忘、分离、轮回控制、社会分裂。光明势力、抵抗运动和觉醒者的工作被放在解除此链条的位置。

### 转化链

转化路径通常是：觉察编程与植入物 -> 连接高我/本源 -> 清理多维身体 -> 冥想与集体锚定 -> 女神/爱/合一能量回归 -> 事件/揭露/疗愈/扬升。

### 关系链

血缘家庭在资料中常被视为地球矩阵的一种社会基础结构；灵魂家族被视为更真实的归属结构。灵魂伴侣和双生灵魂不是浪漫标签，而是与灵魂频率、使命共振、爱场打开和神圣结合相关的高阶关系主题。
