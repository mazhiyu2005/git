# 提示词模式

## 图片提示词基础结构

```text
主体：{人物/动物/道具/产品}
场景：{地点、时代、天气、背景物}
光线：{自然光/逆光/侧光/体积光/黄昏暖光}
构图：{景别、视角、镜头焦段、主体位置}
色调：{暖色/冷色/低饱和/高对比/胶片}
风格：{电影写实/动画/水墨/赛博朋克/广告质感}
一致性：保持{角色/服装/道具/场景}与前序镜头一致
```

示例：

```text
侧面视角，黄昏时分，一个身穿红色长裙的女孩站在海边岩石上望着夕阳，暖色调，写实风格，海风吹动长发，电影级自然光，浅景深，细节丰富，16:9
```

## 视频一致性提示

视频提示词必须同时写清三类一致性：

- 风格一致性：电影风格、色调、光线、镜头语言、质感。
- 场景一致性：参考图重绘法；让参考图生成相似场景，再在该场景中生成主体。
- 主体一致性：人物、动物、植物、道具、产品都要有稳定描述。

可用参考图方法：

- 实拍参考。
- 地图/卫星图参考。
- 天空盒或 360 度场景参考。
- 首帧、尾帧、中间关键帧、前后衔接关键帧。

## Seedance 分镜提示词

```text
【风格】{电影级写实/动画/科幻/水墨等}，{时长}秒，{画幅}，{氛围}
【角色】{角色稳定设定}
【场景】{场景稳定设定}
【时间轴】
0-3秒：{景别/运镜}，{画面内容}，{动作}，{情绪或特效}
3-7秒：...
7-11秒：...
11-15秒：...
【声音】{配乐风格} + {环境音} + {动作音效} + {对白/旁白}
【参考】@图片1 作为角色参考，@图片2 作为场景参考，@视频1 参考运镜
【要求】保持人物、服装、道具、场景、色调和镜头语言一致
```

## 小说转分镜

1. 提炼小说段落：人物、地点、冲突、动作、情绪、关键物。
2. 按画面可见内容改写，删掉纯心理描写或改成表情/动作。
3. 每个镜头只表现一个主要动作或信息。
4. 对白和旁白要短，给画面留空间。
5. 输出镜头表，再输出图像提示词和视频提示词。

## 镜头语言速查

- 推镜：强调主体、逼近真相、制造压迫。
- 拉镜：展示环境、制造疏离或结尾落版。
- 跟拍：跟随行动，增强沉浸感。
- 环绕：展示主体全貌或制造情绪包围。
- 升降：从宏观到细节，或从弱小到宏大。
- 手持：纪实、混乱、紧张。
- 希区柯克变焦：心理冲击、空间压迫。
- 快速摇摄：转移注意力、制造节奏。

## 常用风格词

- 影视风格：王家卫、黑泽明、港片霓虹、韩剧慢镜头、BBC纪录片、Netflix惊悚、黑色电影、赛博朋克、未来科幻。
- 画面质感：胶片颗粒、VHS噪点、8K高清、油画、水彩、HDR、梦幻光斑、广告质感。
- 灯光色调：霓虹紫蓝、黄昏暖光、阴雨蓝灰、窗户光影、森林穿透光、火焰照明、体积光。
- 平台风格：抖音人物特写、小红书淡粉种草、B站二次元卡点、品牌广告包装、电商展示、影视混剪。
