# Chapter Workflow

Use this reference for drafting chapters, continuing excerpts, or turning an outline into scenes.

## Chapter Brief

Before writing, infer or create:

- **Chapter function**: hook, setup, complication, midpoint turn, crisis, aftermath, reveal, payoff, transition.
- **POV and distance**: whose perception controls the chapter and how close the narration sits to their thoughts.
- **Opening pressure**: a question, danger, desire, deadline, social discomfort, image, or decision.
- **Scene chain**: 2-5 scenes or beats, each causing the next.
- **Turn**: the chapter's main reversal, discovery, loss, choice, or relationship shift.
- **Exit hook**: the last paragraph's propulsion.

## Drafting Rules

- Start as late as possible, close before the energy drains.
- Let dialogue have agenda. Characters should want something from each exchange.
- Pair external action with internal pressure; do not let introspection float away from the scene.
- Use concrete sensory detail when it changes mood, reveals character, or anchors action.
- Make choices costly. If the protagonist wins, let the win create a harder problem.
- End chapters with changed information, changed danger, changed relationship, or a changed self-understanding.

## Continuation Protocol

When continuing existing prose:

1. Identify the last active question and emotional charge.
2. Preserve names, diction, pacing, POV, tense, and paragraph rhythm.
3. Resolve only the nearest beat unless the user asks for a major jump.
4. Introduce no major new lore unless it pays off prior setup or creates a clear new hook.
5. Continue in prose, then add a brief note only if continuity changed.
