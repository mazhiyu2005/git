# Revision

Use this reference for critique, rewriting, prose polish, and structural repair.

## Diagnosis Order

Review from large to small:

1. **Story promise**: Does the passage deliver the genre, tone, and reader expectation?
2. **Scene purpose**: What changes by the end?
3. **Causality**: Does each beat happen because of character choice, pressure, or established rules?
4. **Motivation**: Do choices make emotional and practical sense?
5. **Pacing**: Are exposition, action, dialogue, and reflection balanced for the intended effect?
6. **Voice**: Does narration sound like this story, not generic prose?
7. **Line craft**: Cut redundancy, sharpen images, vary rhythm, strengthen verbs, remove filler.

## Revision Modes

- **Light polish**: keep structure and meaning; improve rhythm, diction, clarity, and texture.
- **Line edit**: rewrite sentences and paragraphs while preserving plot beats.
- **Scene rewrite**: rebuild conflict, tactics, turn, and emotional movement.
- **Structural edit**: recommend moving, cutting, adding, or reframing scenes.
- **Market edit**: adjust hooks, pacing, chapter endings, readability, and genre satisfaction.

## Common Fixes

- If the scene feels flat, clarify the want, obstacle, and consequence.
- If dialogue feels on the nose, give each speaker a hidden agenda and let them avoid saying the core truth directly.
- If exposition drags, attach it to danger, desire, mystery, status conflict, or a decision.
- If prose feels generic, add viewpoint-specific perception and remove abstract summary.
- If pacing is too fast, add reaction beats and sensory anchors; if too slow, cut repeated thoughts and combine beats.

## Output Format

For critique:

```markdown
**Diagnosis**
...

**Highest-impact fixes**
1. ...
2. ...
3. ...
```

For rewriting, provide the revised passage first when the user mainly wants usable text. Keep commentary brief.
