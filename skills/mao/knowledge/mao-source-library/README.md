# 毛泽东资料库

本资料库用于后续聊天、检索和本地知识库整理。当前包含官方/机构页面抓取的《毛泽东选集》第一至四卷，以及从“毛泽东博览”补充抓取的《毛泽东文集》、毛选五卷和若干专题资料。

## 优先使用
- `qstheory-index.json` + `qstheory-pages/`: 求是网《毛泽东选集》第一至四卷，169 个分页，正文完整。
- `mzdbl-text-index.json` + `mzdbl-texts/`: 补充文本资料，包含《毛泽东文集》第一至八卷、毛选五卷、党建、文艺、报刊、诗词、语录等。
- `mzdbl-pdf-manifest.json`: 毛泽东博览 PDF/压缩包下载清单；`mzdbl-pdfs/` 下为已下载原件。
